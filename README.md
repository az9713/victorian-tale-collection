# The Wager Ledger

An illustrated Victorian mystery in which Sherlock Holmes and Phileas Fogg cross paths across the late Victorian age.

- [Book 1: The Snuffbox (1881)](https://az9713.github.io/the-wager-ledger/the-snuffbox.html)
- [Book 2: The Cable (1887)](https://az9713.github.io/the-wager-ledger/the-cable.html)
- [Development Journey: how the human writer steered the stories](https://az9713.github.io/the-wager-ledger/development-journey.html)

The stories were written in partnership between a human writer and an AI drafting assistant. The illustrations were created with GPT Image2.
